# Registros de Decisões Arquiteturais (ADRs)

Este diretório contém os Registros de Decisões Arquiteturais (Architecture Decision Records — ADR) do ScaryParty.  
Use este padrão para registrar decisões estruturais duradouras (tecnologias, pipelines, padrões de rede, etc.).

---

## Modelo de ADR

Cada ADR deve seguir o formato:
- **Título:** `ADR-XXXX-nome-da-decisao.md`
- **Status:** Proposto / Aceito / Substituído / Depreciado
- **Contexto:** Qual era o problema ou requisito técnico?
- **Decisão:** O que foi escolhido e por quê?
- **Consequências:** Quais os trade-offs, benefícios e impactos colaterais?
