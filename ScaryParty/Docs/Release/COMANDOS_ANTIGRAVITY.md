# Mensagens para colar no Antigravity

Os caminhos abaixo partem da raiz Git deste repositório. Se você abriu diretamente a raiz Unity no Antigravity, remova apenas o prefixo `ScaryParty/`.

## Iniciar M1

```text
Leia ScaryParty/Docs/Release/ROADMAP.md e ScaryParty/Docs/Release/CONTRATO_EXECUCAO.md. Execute completamente ScaryParty/Docs/Release/Prompts/M1_Auditoria.md, incluindo implementação, correções, verificações disponíveis e relatório. Continue até concluir todo o trabalho possível desta fase. Registre testes manuais pendentes sem alegar que foram executados. Não avance à fase seguinte.
```

## Retomar a fase em outra conversa

```text
Leia ScaryParty/Docs/Release/STATUS.md, o relatório da fase ativa e seu prompt. Compare o checkpoint com o git status e retome da próxima ação pendente. Preserve o trabalho existente, não repita auditorias já documentadas sem motivo e não avance à fase seguinte. Conclua as tarefas possíveis e registre separadamente validações que dependem do Unity.
```
